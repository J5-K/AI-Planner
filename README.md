# AI 동적 플래너

사용자가 해야 할 일을 자연어로 입력하면 계획에 필요한 정보를 구조화하고, 부족한 조건을 질문으로 보완한 뒤 실행 가능한 일정을 생성하는 LangChain 기반 플래너입니다. 최초 계획이 어긋나거나 새로운 일정이 생겼을 때 완료하지 못한 작업을 남은 시간에 재배치하는 것을 목표로 합니다.

## 프로젝트 목표

혼자 계획을 구체화하기 어렵거나, 계획이 한 번 어긋난 뒤 다시 조정하기 어려운 사용자를 돕습니다.

사용자가 할 일만 입력해도 다음 과정을 통해 현실적인 계획을 만들 수 있어야 합니다.

```text
할 일 입력
→ 할 일과 제약 조건 구조화
→ 부족한 정보 질문
→ 최초 계획 생성
→ 시간 및 일정 충돌 검증
→ 수행 결과와 새 일정 입력
→ 미완료 작업 재계획
```

## 핵심 기능

1. **할 일 구조화**
   - 자연어 입력에서 작업, 마감일, 예상 시간, 우선순위 등을 추출합니다.
2. **부족한 정보 질문**
   - 계획 생성에 필요한 정보가 없으면 이를 판별하고 추가 질문을 생성합니다.
3. **계획 생성**
   - 작업을 우선순위, 마감일, 가용 시간에 맞게 배치합니다.
4. **시간 검증**
   - 작업시간 합계와 가용 시간을 비교하고 과부하 및 일정 충돌을 확인합니다.
5. **미완료 작업 재계획**
   - 완료하지 못한 작업과 새로 생긴 고정 일정을 반영해 남은 계획을 수정합니다.

## MVP 범위

### 포함

현재 입력 구조화, 조건부 후속 질문, 계획 생성, 시간 검증, 간단한 재계획까지 구현되어 있습니다. LLM은 자연어 이해와 작업 순서 판단을 담당하고 Python은 반복 일정 확장, 빈 시간 계산, 작업 배치와 충돌 검증을 담당합니다.

## 설치 및 실행

### 1. 가상환경 생성

macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Windows PowerShell:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
```

### 2. 패키지 설치

```bash
python -m pip install -r requirements.txt
```

### 3. 환경변수 설정

`.env.example`을 복사해 `.env`를 만들고 OpenAI API 키를 입력합니다.

macOS/Linux:

```bash
cp .env.example .env
```

Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

```dotenv
OPENAI_API_KEY=your_api_key_here
```

`.env`는 Git에 커밋하지 않습니다.

### 4. 실행

현재 입력 구조화 테스트:

```bash
python app.py
```

터미널에서 질문에 답하려면 `python app.py`를 실행합니다.

웹 화면으로 실행하려면 다음 명령을 사용합니다.

```bash
python gradio_app.py
```

출력된 로컬 주소(일반적으로 `http://127.0.0.1:7860`)를 브라우저에서 엽니다.
최초 계획을 만든 뒤 `계획이 어긋났나요? 재계획하기` 영역에 미완료 작업과
새 약속을 자연어로 입력하면 남은 작업을 다시 배치할 수 있습니다.

웹 화면에서는 다음 기능을 추가로 제공합니다.

- 체크박스로 미완료 작업 선택
- 새 약속을 날짜와 시작·종료 시간으로 입력
- 최초 계획과 재계획의 유지·이동·추가·제외 항목 비교
- 일정 표에서 날짜와 시간을 직접 수정한 뒤 재검증
- LangChain 가상 캘린더 Tool을 통한 고정 일정 조회와 충돌 검사
- 원문 기반 요일 불가 조건 재검증 (`토요일 불가` 등)
- 빠른 완료·균등 분산·여유일 확보 계획 방식 선택
- 계획 기간과 실제 예상 완료일 비교 안내
- 여러 주를 날짜별 카드로 보여주는 주간 캘린더

## 데이터 모델

| 모델              | 역할                                                |
| ----------------- | --------------------------------------------------- |
| `Task`            | 작업명, 예상 시간, 마감일, 우선순위, 분할 가능 여부 |
| `RecurrenceRule`  | 매일·매주·매월 및 간격을 표현하는 반복 규칙         |
| `FixedEvent`      | 변경할 수 없는 단일 또는 반복 일정                  |
| `AvailableSlot`   | 특정 날짜 또는 반복 요일의 작업 가능 시간대         |
| `PlanningContext` | 목표, 작업, 가용 시간, 누락 정보 등 계획 전체 조건  |
| `ScheduleItem`    | 특정 날짜와 시간에 배치된 작업                      |
| `Plan`            | 생성된 전체 일정과 경고 및 설명                     |
| `PlanUpdate`      | 완료, 미완료, 새 고정 일정 등 변경 사항             |

## 시연 시나리오

### 최초 입력

```text
이번 주 일요일까지 LangChain 프로젝트를 완성해야 한다.
해야 할 일은 주제 확정, 핵심 기능 개발, UI 구현, 발표 자료 작성이다.
수요일 저녁에는 약속이 있다.
```

AI는 작업별 예상 시간, 하루 가용 시간, 우선순위, 작업 분할 가능 여부 등 부족한 정보를 질문합니다.

### 계획 실패 및 새 일정

```text
화요일의 핵심 기능 개발을 완료하지 못했다.
목요일 저녁에도 새로운 약속이 생겼다.
```

### 기대 결과

- 완료한 작업은 유지합니다.
- 미완료 작업은 남은 시간으로 이동합니다.
- 새 약속과 충돌하는 작업을 재배치합니다.
- 마감일과 우선순위를 유지합니다.
- 시간이 부족하면 일정을 억지로 배치하지 않고 경고와 축소안을 제시합니다.

## 완료 조건

다음 흐름이 한 번에 동작하면 MVP가 완성된 것으로 판단합니다.

1. 사용자가 LangChain 프로젝트 준비 작업을 입력합니다.
2. AI가 입력을 구조화하고 부족한 정보를 질문합니다.
3. 답변을 반영해 최초 계획을 생성합니다.
4. 사용자가 미완료 작업과 새로운 약속을 입력합니다.
5. 완료한 작업은 유지하면서 남은 작업이 충돌 없이 재배치됩니다.
6. 변경된 일정과 변경 이유가 표시됩니다.

## 설계 원칙

- LLM은 자연어 이해, 누락 정보 판단, 우선순위 해석, 변경 이유 설명을 담당합니다.
- Python은 시간 합산, 슬롯 계산, 충돌 검사 등 정확한 계산을 담당합니다.
- 사용자가 제공하지 않은 날짜와 시간을 사실처럼 생성하지 않습니다.
- 가용 시간보다 필요한 시간이 많으면 경고하고 사용자에게 범위 조정을 요청합니다.
- 실제 캘린더 저장이나 외부 서비스 변경은 사용자 승인 없이 수행하지 않습니다.
